---

### 🔴 SLAID 8: KELEBIHAN TEKNIKAL & ARCHITECTURE
** Visual Slaid**: *Diagram Dwi-Enjin Pangkalan Data (MySQL 🔄 SQLite Auto-Fallback).*

> **🗣️ Skrip Pertuturan:**
>
> "Dari sudut teknikal dan kebolehpercayaan:
> 1. **Dual-Engine Automatic Fallback Database**: Sistem disokong enjin MySQL utama. Namun, jika pelayan MySQL terputus sambungan, sistem bertukar secara automatik ke **SQLite Embedded Database** tanpa merosakkan paparan pengguna (*Zero Downtime*).
> 2. **Standard Keselamatan**: Menggunakan *BCRYPT Password Hashing*, *PDO Prepared Statements* (bebas SQL Injection), dan sanitasi input XSS.
> 3. **Pelancaran Mudah & Cloud Ready**: Dilengkapi *Dockerfile* dan *vercel.json*, sedia untuk dilancarkan di pelayan awan seperti Railway."

## 💡 PANDUAN MENJAWAB SOALAN PANEL / JURI (Q&A CHEAT SHEET)

### ❓ Soalan 1: "Kenapa sasarkan kepada Sekolah Rendah & PPKI?"
> **Jawapan:**
> "Pendedahan awal kerjaya mengikut kajian perkembangan kanak-kanak perlu dipupuk sebelum umur 12 tahun untuk membina matlamat kendiri. PPKI juga diberi perhatian dengan reka bentuk UI visual yang ringkas dan warna kontras mesra murid pendidikan khas."

### ❓ Soalan 2: "Bagaimana sistem ini mengendalikan isu keselamatan data murid?"
> **Jawapan:**
> "Semua data dilindungi dengan *PDO Prepared Statements* untuk menghalang SQL Injection, kata laluan pentadbir di-hash menggunakan algoritma BCRYPT, dan setiap pergerakan pencerobohan direkodkan dalam *Audit Log Keselamatan 24/7*."

### ❓ Soalan 3: "Adakah enjin AI memerlukan lesen berbayar?"
> **Jawapan:**
> "Tidak. Enjin AI disepadukan secara fleksibel menggunakan kuota percuma Google Gemini API / Groq Llama 3.3, dan penjanaan gambar menggunakan *Pollinations AI* yang percuma tanpa had."

### ❓ Soalan 4: "Bagaimana jika sekolah tiada pelayan database MySQL yang canggih?"
> **Jawapan:**
> "Sistem mempunyai ciri *Dual-Engine Database Fallback*. Jika MySQL tidak tersedia, sistem akan mengaktifkan *embedded SQLite database* secara automatik tanpa sebarang konfigurasi manual."
